# Kelime Tahtası · Word Board

Taşları diz, rakibini puanla geç!

Raftan bir taş seç, tahtada boş kareye dokun. Kelimeler tek sırada ve tahtadaki taşlara bitişik olmalı; ilk kelime yıldızdan geçer. Renkli kareler puanı katlar. Belirli turdan sonra yüksek puan kazanır.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
